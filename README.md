# 🥗 NutriSync  
## Personal Nutritionist & Health Analysis System

NutriSync is a Flask-based web application that acts as a smart personal nutritionist and health dashboard.  
The system analyzes user health data, calculates nutrition metrics, generates visual reports, and provides health recommendations through an interactive modern UI.

---

# 🚀 Features

✅ BMI Calculation  
✅ Daily Calorie Requirement Analysis  
✅ Protein, Carbohydrate & Fat Calculation  
✅ Water Intake Recommendation  
✅ Health Score System  
✅ Nutrition Dashboard UI  
✅ Graph Generation using Matplotlib  
✅ CSV Data Storage using Pandas  
✅ Flask-Based Web Application  
✅ Responsive Dark-Themed Interface

# 💡 How It Works

1️⃣ User enters health details  
2️⃣ Flask processes the data  
3️⃣ Python calculates health metrics  
4️⃣ Pandas stores records in CSV  
5️⃣ Matplotlib generates graphs  
6️⃣ Dashboard displays full health analysis

## 1️⃣ Install Required Libraries
